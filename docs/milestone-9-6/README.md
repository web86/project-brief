# Milestone 9.6 — Universal Agent API & External Executors

Project Brief v0.9.6, база v0.9.5. Ветка `codex/milestone-9-6-agent-api`.

- Workspace-регистрация внешнего исполнителя без фиктивного человека или email. Тип подключения не выдаёт права. Управление и секреты — только владельцу с существующим MFA/fresh confirmation.
- Существующая команда проекта дополнена агентами. Владелец явно разрешает проекты; суперадминистратор управляет назначениями только в своих проектах. Участники проекта назначают агенту задачи.
- Пять отдельных scopes; доступ пересекается с workspace, owner grant, project membership и активным назначением. Отзыв действует после завершения операции.
- Отчёты, комментарии и файлы используют обычные комментарии/вложения с авторством агента. История и ссылки результатов сохраняются после снятия назначения/удаления регистрации. Execution state не меняет статусы задач и клиентское согласование.
- Минимальные подписанные webhooks через существующую outbox, retries/SSRF и проверка доступа перед доставкой. Независимый Node.js пример работает и без webhook. Новых процессов на Jino нет.

Контракты: [API](AGENT-API.md), [OpenAPI](openapi.json), [webhooks](AGENT-WEBHOOKS.md), [безопасность](AGENT-SECURITY.md), [пример](AGENT-EXAMPLE.md), [инструкция запуска](examples/README.md), [deployment/rollback](PRODUCTION.md). Результаты проверки и артефакт фиксируются в RELEASE.md.

AI-провайдер, полноценный MCP-сервер, тарифы/биллинг не реализуются. Владелец осознанно разрешает передачу содержимого выбранных задач внешнему исполнителю. Production, push и deployment не изменяются.
