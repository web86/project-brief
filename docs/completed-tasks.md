# Готовые карточки

Проверено 5 октября 2026 года.

`src/utils/tasks.js` выполняет стабильное разделение списка: активные идеи,
затем готовые. ProjectView применяет helper внутри каждого раздела после фильтрации.
Порядок обеих групп сохраняется, исходный массив и объекты задач не изменяются.

TaskCard остаётся RouterLink со всем прежним содержимым. Overlay скрыт от
screen reader, не перехватывает указатель и не отключает саму ссылку.
Hover и keyboard focus делают фон overlay прозрачнее; сохраняется общая рамка фокуса.

Проверки в браузере:

- 1440×900: три колонки, первый ряд целиком виден. Карточка «Готово» открывается
  клавишей Enter; Shift+Tab переводит фокус на ссылку с рамкой 3 px.
- Раздел «Контакты»: активная идея переместилась перед готовой в том же разделе.
- Фильтр «Готово»: три карточки, три overlay, активных карточек нет.
  Клик открывает исходный URL задачи.
- 390×844: одна колонка шириной 354 px, ширина страницы 390 px,
  горизонтальной прокрутки нет. Клик по готовой карточке открывает страницу идеи.
- Название и счётчик комментариев остаются в доступном имени ссылки;
  вложения и весь контент остаются в DOM под overlay.
- Консоль: ошибок и предупреждений нет.
