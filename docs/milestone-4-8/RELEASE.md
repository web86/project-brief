# Project Brief 0.4.8 — Developer Invitations & Account Profile

Владелец приглашает разработчиков в проекты своего workspace, меняет назначения и отзывает доступ. Новый разработчик создаёт аккаунт только по приглашению; существующий входит в свой аккаунт. Один User участвует в нескольких workspace, без глобальной роли администратора.

Добавлены «Команда» и глобальный «Мой аккаунт»: профиль, безопасность, прежние личные уведомления Milestone 4.6. Подтверждение нового Email сохраняет прежний адрес до перехода по ссылке. Смена/восстановление пароля отзывает остальные сеансы; восстановление использует Laravel Password Broker. Аватары: initials по умолчанию, добровольный Gravatar SHA-256, безопасная загрузка с преобразованием в private WebP.

В навигации используются AppIcon и общая конфигурация desktop/mobile: иконки 20px, активный фон/currentColor, счётчики справа, разделитель корзины. Добавлены недостающие встроенные `users`, `settings`, `list-tree`; новая библиотека не устанавливалась. Клиенты и команда остаются разными разделами.

Обновление требует новой additive миграции, Argon2id и GD WebP. См. PRODUCTION.md: установка, ручная приёмка SMTP Jino, план отката и совместимость паролей. Архив включает production vendor и assets; `.env`, БД, uploads, tests, developer tools и secrets не включаются.

Push, deployment и GitHub Release не выполнялись. Проверку реальной доставки SMTP Jino пользователь проводит самостоятельно.
