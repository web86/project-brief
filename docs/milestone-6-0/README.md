# Milestone 6.0 — Multilingual Expansion

Project Brief поддерживает Русский, English и Türkçe через существующий vue-i18n и штатные Laravel lang-файлы. В каждом frontend-словаре 782 одинаковых ключа. Новых зависимостей, полей БД и миграций нет.

## Выбор языка

Приоритет: ручной выбор на устройстве → `preferred_locale` профиля → первый язык браузера → English. Неподдерживаемые и повреждённые значения не применяются. Выбор меняет `<html lang>`, строки и Intl-форматирование без перезагрузки. `PATCH /api/admin/me/locale`, `PATCH /api/client/me/locale` и настройки аккаунта сохраняют существующее поле `preferred_locale`. На новом устройстве профиль имеет приоритет над языком браузера. Автоматическое определение языка не меняет профиль.

Единый frontend-каталог: `src/i18n/catalog.js`, переэкспортируемый из `src/i18n/index.js`. Backend: `api/config/localization.php` и `SupportedLocales`. Контроллеры профиля и экспорта, уведомления и ответы Telegram используют этот allowlist. Тест проверяет одинаковые коды и Intl-регионы с обеих сторон. API получает текущий язык интерфейса через `Accept-Language`; сервер учитывает профиль и браузерный заголовок для остальных запросов.

AI-интерфейс и служебные ошибки переведены. Инструкция AI уже сохраняет язык исходной задачи; она и поведение генерации не менялись. Смена языка интерфейса не запускает перевод пользовательского текста.

## Как добавить следующий язык

1. Создать `src/locales/xx.js` с полным набором ключей EN. Сохранить имена подстановок, заполнить все строки, подобрать формы множественного числа. `bootstrap` — часть того же словаря.
2. Добавить `{ code: 'xx', name: 'Native name', intl: 'xx-YY', messages: xx }` в `src/i18n/catalog.js`. Компоненты и бизнес-логика не меняются.
3. Добавить код и настройки `intl`, `group`, `decimal`, `approval_date` в `api/config/localization.php`. Коды должны точно совпадать с frontend-каталогом.
4. Перевести `api/lang/xx/{account,exports,interface,notifications}.php`. Сохранить `:name`, `:project`, `:count` и другие параметры. Заполнить все события и ответы Telegram.
5. Только если язык требует особых правил, добавить правило множественного числа в существующий vue-i18n `pluralRules`. Laravel использует штатный `trans_choice`. Не добавлять редактор или таблицы переводов.
6. Выполнить `npm test`, `npm run build`, `cd api && php artisan test --compact`, `vendor/bin/pint --dirty --format agent`. Проверки автоматически сравнят ключи, непустые значения, параметры и серверный каталог.
7. Выполнить `PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node tests/multilingual.browser.mjs`. Матрица читает языки из каталога; Проверить длинные подписи, поиск, регистр, мобильную навигацию и шрифты PDF/DOCX.
8. Закоммитить проверенный код; `./bin/build-release` создаст ZIP после тестов и проверки состава. Требуемые языковые файлы для ZIP автоматически проверяются в `deployment/release-files.mjs` по каталогу.

## Состав изменений

- Frontend: каталог и словари; Vite-генерация загрузчика; форматирование поиска/инициалов; переключатели аккаунта/экспорта; заголовки уведомлений и роль в обсуждениях; защита от неизвестных ключей ошибок.
- Backend: `SupportedLocales`, config и middleware; валидация профиля/экспорта; сервисы доставки и Mailable; Laravel-словари RU/EN/TR; переводы шаблонов, стартовых разделов и резервных текстов API.
- Проверки: i18n unit-тесты, адаптация PWA-теста загрузчика, Laravel `ClientLocaleTest`/`MultilingualTest`, изолированная browser fixture и E2E-матрица.
- Релиз: версия 0.6.0, обязательные языковые файлы, актуальные release notes/инструкция и копирование отчёта со снимками в `GUIDES/milestone-6-0`.

Права, каналы, получатели, очередь и интеграционные события не изменены. Production deployment не выполнялся.
