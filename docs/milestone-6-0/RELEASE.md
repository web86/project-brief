# Project Brief 0.6.0 — RU / EN / TR / ZH-CN

Milestone 6.0 завершён добавлением 简体中文: 782 frontend-ключа, четыре Laravel-словаря, Email/Telegram/Push и системные письма, независимый язык PDF/DOCX. RU/EN/TR проходят повторную регрессионную проверку.

Браузерные zh-CN/zh-Hans/zh-SG выбирают упрощённый китайский; традиционный китайский получает English fallback. Ручной выбор и профиль сохраняют приоритет. В существующем двухсимвольном поле китайский хранится как `zh`; API и интерфейс используют `zh-CN`.

Добавлены локальные лицензированные Noto Sans SC для настоящих CJK-глифов, переносов и встраивания PDF/DOCX. Пользовательский текст и валюта сохраняются. Новых runtime-зависимостей, миграций и env-переменных нет. Устанавливать согласованные public/private по PRODUCTION.md, включая resources/fonts.

Отчёт, 24 desktop/mobile снимка, результаты тестов и образцы экспорта находятся в GUIDES/milestone-6-0. Реальная отправка уведомлений, push Git и production deployment не выполнялись.
