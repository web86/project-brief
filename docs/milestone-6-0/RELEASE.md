# Project Brief 0.6.0

Добавлена полноценная локализация Türkçe для интерфейса, профиля, всех событий Email/Telegram/Push, сервисных писем и PDF/DOCX. RU/EN сохраняются; словари, параметры и allowlist проверяются автоматически. Каталог языков управляет всеми переключателями, а загрузчик получает переводы из тех же словарей при сборке.

Выбранный язык сохраняется в `preferred_locale` без перезагрузки. На новом устройстве используется язык профиля. Экспорт имеет отдельный язык; исходные задачи, комментарии, названия и валюта проекта сохраняются. Поиск и инициалы учитывают турецкий регистр.

Новых зависимостей, миграций и настроек окружения нет. Установить согласованный комплект public/private по PRODUCTION.md. Отчёт, результаты, инструкция следующего языка, desktop/mobile screenshots и образцы экспорта включены в GUIDES/milestone-6-0.

Релиз подготовлен локально. Отправка реальным получателям и production deployment не выполнялись.
