`browser-results.json` фиксирует матрицу, `export-results.json` — извлечение Unicode. В `export-tr-pdf.png` и `export-tr-docx.png` сохранены проверенные страницы. Названия разделов и пользовательский текст не переводятся между языками документа.

В ходе повторного запуска исправлены устаревшие ожидания тестов о недопустимости `tr`, тест раннего загрузчика адаптирован к генерации словаря, а приватный тест авторства проверяет резервную роль на текущем языке. Проверки прав, доступов, сессий, интеграций и очередей проходят в общем наборе.

Команды воспроизведения:

```sh
npm test
npm run build
cd api
php artisan test --compact
vendor/bin/pint --dirty --format agent
```

Из корня репозитория для браузера:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs npm run test:multilingual
```

Используется отдельная временная SQLite-БД с защитой имени каталога; реальные БД и отправка уведомлений не используются. Серверы получают свободные локальные порты и завершаются после теста. При необходимости диагностики добавить `E2E_DEBUG=1`.

`./bin/build-release` запускается с чистого коммита, повторяет unit/build/Laravel, проверяет состав и отсутствие секретов, устанавливает production vendor в staging, выполняет `tests/release-runtime.mjs` на отдельной копии приложения и только затем создаёт ZIP. В packaged runtime также проверяются RU/EN/TR для сохранения языка и шаблонов Email. Source commit указан в `release.json`; итоговые данные архива и SHA-256 публикуются рядом с отчётом после сборки.

Реальная доставка SMTP/Telegram/Web Push и ручная установка PWA на физические iOS/Android-устройства не проверялись; это не требуется для локальной сборки и не подменяется транспортными тестами. Production deployment не выполнялся.
