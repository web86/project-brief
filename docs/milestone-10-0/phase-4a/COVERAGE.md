# Entitlement coverage matrix — Phase 4A

All rows retain **existing authorization AND workspace/object scope**. Shadow decisions cannot grant access or reject an authorized business action. Missing/expired pinned entitlement is unknown; no hidden switch enables enforcement. Expiry of a credential/session remains an existing authorization denial. W=workspace mutex/current recheck before mutation; R=read observation (no new workspace mutation lock); safe reductions never require premium capacity. All tariff side effects below are proposals only.
