# Project Brief 0.4.8.2 — Project Member Permissions

Владелец настраивает шесть прав каждого разработчика отдельно в каждом проекте: структура, клиенты, настройки, проектные уведомления, экспорт и корзина. По умолчанию доступна только структура; идеи, комментарии, вложения и личные настройки сохраняются. Сервер проверяет права на каждом запросе, общий desktop/mobile sidebar и маршруты отражают эффективные разрешения проекта.

Отдельное разрешение участника workspace позволяет создавать собственные проекты, по умолчанию выключено. Созданный проект автоматически назначается разработчику с базовыми правами; owner-роль, управление командой и создание workspace не делегируются. Владелец может отозвать создание проектов независимо от прежних назначений.

Новая миграция добавляет nullable JSON к project_members и boolean default false к workspace_members. Пользователи, назначения, история и интеграции сохранены. Поставка включает Milestone 4.8/4.8.1 и принятые улучшения клиентского меню/личных уведомлений. Инструкции обновления и отката — PRODUCTION.md.

Полный ZIP содержит production vendor и frontend assets, без действующего .env, БД, uploads, логов, тестов и секретов. Push, deployment и GitHub Release не выполнялись. Deno bridge не изменён.
