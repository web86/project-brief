# Экспорт ProjectBrief — Milestone 6.2

PDF: Laravel JSON API → Web Worker → pdfmake → скачивание. DOCX: Laravel → PHPWord → скачивание. Серверный PDF, Dompdf и автоматический fallback отсутствуют.

На той же странице экспорта выберите заголовок, задачи (все/согласованные/выполненные), поля, язык документа и разрыв по разделам. Нажмите «Экспорт PDF» или «Экспорт DOCX». Язык документа независим от языка интерфейса, валюта остаётся валютой проекта. Администратору доступны разрешённые ему настройки, клиенту — шесть безопасных полей без часов, цен и технических заметок.

Пустой проект или фильтр без задач возвращает понятное локализованное сообщение; пустой файл не скачивается. Новый проект сначала требует ручного добавления раздела и задач. Существующие проекты не изменяются.

PDF показывает этапы подготовки, загрузки компонентов/шрифтов, формирования и скачивания. Отмена прекращает запрос/Worker и освобождает ресурсы. Ошибка позволяет повторить операцию с теми же настройками. При ошибке серверная PDF-генерация не запускается. DOCX остаётся серверным, его содержимое и встройка CJK-шрифтов сохранены.

DejaVu Sans и Noto Sans SC загружаются динамически. Noto нужен только для CJK в системных подписях или пользовательском тексте. Публичный кеш содержит исключительно TTF, приватный JSON не сохраняется в постоянных хранилищах. Первый набор CJK-шрифтов велик (21,6 МиБ вместе с DejaVu); последующие экспорты используют кеш при его доступности. При недоступном кеше экспорт выполняется обычной загрузкой. Лицензии находятся в `font-licenses` публичной сборки.

Действуют защитные лимиты API: 1000 выбранных задач, 2 МиБ выбранного текста задач, 8 МиБ JSON, по умолчанию 5 запросов в минуту на сессию. UI дополнительных ограничений не вводит. Эти лимиты не гарантируют успешную обработку любых данных на любом устройстве. PHP memory_limit не повышается.

Проверены Chromium/Firefox и mobile viewport. Совместимость Safari и физических смартфонов не объявляется подтверждённой. Масштабные измерения предыдущего прототипа сохранены в истории Milestone 6.1, commit cd008cd.
