# Проверка UX/UI cleanup

5 октября 2026 года. Работа продолжена поверх существующей main, без новых зависимостей.

## Интерфейс

Удалены большая статистика, зелёный promo-блок, слоган, повторные пояснения,
боковая инструкция формы и большая карточка согласования. Логотип, режимы,
фильтры, progress bar и все действия MVP сохранены.

Нейтральная палитра, body 16 px, labels 15 px, заголовки карточек 18 px,
описания 15 px (16 px на mobile), максимум две строки. Цвета различают статусы
и приоритеты. Необязательные поля выделены отдельно, AI остаётся вторичным действием.

## Поведение и данные

- Прежние десять идей из браузерного localStorage восстановились, включая вложения,
  комментарии, согласование, оценку, стоимость и заметки. Сброса данных не было.
- Ключ `project-brief:v1` и версия 1 сохранены. Старые задачи читаются через
  `location || section`. Новые задачи записывают оба поля для совместимости.
- Выбор «Карточка товара» клавишами ↓ и Enter не отправляет форму.
  Tab закрывает подсказки и переводит фокус; существующий раздел также выбирается указателем.
- Сохранены тестовые идеи с собственным местом «Мобильное меню» и длинным URL
  с query string и hash. Они корректно группируются и фильтруются.
  Полный URL совпадает после перезагрузки; CSS ограничивает только отображение.
- Значение места `all` не конфликтует с пунктом «Все разделы»: фильтр показывает
  ровно одну соответствующую идею, затем возвращается к общему списку.
- Пустая форма показывает ошибки трёх обязательных полей и фокусирует первое.
  Идея сохраняется без ожидаемого результата и вложений.
- Две вставки одного PNG через Cmd+V добавляют два отдельных превью.
  Вставка текста в описание продолжает работать. Изображения из буфера проходят
  прежние проверки формата, размера, количества файлов и сохранение превью.
- На новой тестовой идее добавлены сообщения клиента и разработчика,
  согласование, статус «В работе», 2,5 часа, 7500 ₽ и техническая заметка.
  Все значения восстановились после обновления страницы.
- В клиентском режиме developer-only поля скрыты. История изначально закрыта,
  открывается и закрывается с клавиатуры; внутренние события скрыты от клиента.
- AI-демо открывается на mobile, Escape закрывает окно и возвращает фокус.
  Заполненная форма сохраняется. API не подключён.
- Консоль браузера: ошибок и предупреждений нет.

Тестовые идеи оставлены в браузере с префиксом «Проверка UX»; прежние идеи не менялись.
