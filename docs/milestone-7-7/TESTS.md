# Проверки Milestone 7.7

Локальная среда: macOS, PHP 8.5.10, Laravel 13.34, PHPWord 1.4.0, pdfmake 0.3.13, Chromium/Firefox Playwright. Зависимости приложения не изменены.

## Функциональность

- Frontend `npm test`: **318/318 PASS**.
- Новый `DocumentPresentationTest`: **6 PASS / 2356 assertions**. Проверены 16 комбинаций status/priority/hours/price × all/approved/done, все дополнительные поля выключены/включены, RU/EN/TR/ZH, клиентская приватность и изоляция workspace, формальное и workflow-согласование, null/zero/partial/full prices, branding flags, SVG/fallback, alpha/размер PNG, OOXML и переносы.
- Реальный интерфейс экспорта: **20 PASS** — Chromium/Firefox × 1440/390 × четыре языка, пустой проект, tablet/font retry и экспорт 500 задач. Настоящие HTTP JSON/PDF/DOCX, PHP `memory_limit=128M`; PDF остаётся в Worker. [Результаты](BROWSER-RESULTS.json).
- Реальный Worker: восемь PDF матрицы и отдельный SVG. SVG PDF: 40 990 байт, 0 растровых XObject; нет PNG-дубликата.
- Проверена передача внутреннего renderer header, безопасный повтор после step-up и сохранность защищённых заголовков API.
- Каноническая сборка, полный backend и проверка распакованного ZIP: результат фиксируется после сборки в `RELEASE-ARTIFACT.json`.

При первом полном прогоне новые тяжёлые CJK-фикстуры исчерпали общий лимит 128 МБ PHPUnit. Два теста рендера изолированы в отдельных процессах по существующему примеру ChineseLocalizationTest; между документами освобождаются циклы PHPWord. Лимит PHP и production-код ради тестов не повышались.

## Производительность и ресурсы

Отдельный последовательный benchmark реального Worker на одинаковых 500 задачах, по три запуска каждого генератора. Медиана `renderMs`: **789.4 → 755.9 ms** (примерно −4.2%); холодный `workerMs`: **2636.8 → 1998.5 ms**. Тёплые запуски используют четыре font cache hits. Это локальное измерение, не SLA для любого устройства. [До](BENCHMARK-BEFORE.json), [после](BENCHMARK-AFTER.json).

500 задач: **106 → 64 страницы (−39.6%)**, **631 969 → 543 557 байт (−14.0%)**. Сокращение обеспечили отступы, отсутствие повторных подписей и компактные шапка/метаданные/сводка/реквизиты. У long-tr размер вырос с 92 272 до 95 929 байт (+4.0%), у minimal — на 2072 байта: новые точные подписи сводки и переносы не гарантируют уменьшение каждого маленького файла. Существенного регресса генерации 500 задач нет.

В 500-task PDF шрифтовые потоки занимают 21 311 байт, один растровый логотип — 30 397 байт; дубликатов логотипа нет. Stress PNG намеренно содержит плохо сжимаемый рисунок: исходные 1024×320 / 30 511 байт уже меньше уменьшенной версии, поэтому сохраняется исходный нормализованный файл. Отдельный тест высокоэнтропийного PNG подтверждает уменьшение до ≤360×117 и сохранение alpha. Геометрический SVG встраивается напрямую; текстовый/namespace-prefixed SVG получает PNG fallback.

CJK-шрифты PDF загружаются только при необходимости и кешируются. Смешанный пример требует 22 644 176 байт font resources при первом запуске, но итоговый PDF содержит подмножества. В брендированных DOCX китайское имя вложения включает прежнее полное встраивание CJK regular/bold: 21 181 416 исходных байт шрифтов, около 12.68 MB после ZIP compression, поэтому DOCX около 12.7 MB. Шрифты намеренно не удалялись ради уменьшения файла. Minimal DOCX без CJK — 9414 байт. Ресурсы каждого документа приведены в аудите.

## Воспроизведение

```sh
cd api
DOCUMENT_EXPORT_QA_DIRECTORY=../artifacts/milestone-7-7/after php artisan test --filter=DocumentPresentationTest
cd ..
BRANDING_EXPORT_QA_DIRECTORY=artifacts/milestone-7-7/after BRANDING_EXPORT_NAMES=small-en,studio-ru,medium-ru,large-en,long-tr,chinese,section-breaks,minimal DOCUMENT_VECTOR_QA=1 node tests/branding-export.browser.mjs
EXPORT_QA_DIRECTORY=artifacts/milestone-7-7/ui-export EXPORT_LARGE_QA=1 node tests/export.browser.mjs
python3 tests/document-export.audit.py artifacts/milestone-7-7
./bin/build-release
```

Playwright/Python/Poppler/LibreOffice нужны только для QA; при отсутствии системных инструментов использован встроенный runtime Codex. DOCX рендерился `render_docx.py --output_dir ... --emit_pdf`, без production-зависимости LibreOffice. Baseline PDF: тот же browser test с `BRANDING_EXPORT_BASELINE_DEFINITION` на сохранённый `before/definition.js`; baseline DOCX создан прежним exporter до изменения production-кода.

Физическая чёрно-белая печать, Safari, конкретный Microsoft Word и production Jino/PHP 8.4/MariaDB здесь не проверялись. Проверка выполнялась на локальном SQLite и одноразовой среде распакованного пакета. Push/merge/deployment не выполнялись.
