**Milestone 4.4.1 — Navigation & Sidebar Polish**

Ветка: `codex/milestone-4-4-1-navigation-polish`. Основа: `main`, `d276e9c`. Изменения только во frontend; backend, БД и зависимости не менялись.

Сделано:

- Правая панель администратора содержит название проекта, прежние семь маршрутов и бейдж обсуждений, заметную ссылку «Все проекты» и профиль текущего авторизованного пользователя с инициалами, фактической ролью и доступной кнопкой выхода. Имя и аватар не являются ссылками. Единственная прокрутка находится у самого dialog; разделение по высоте и компактная копия глобального сайдбара удалены. Если места достаточно, профиль располагается у нижнего края; в коротком окне вся панель прокручивается.
- Обычный `AdminSidebar` сохраняет выбор рабочего пространства, создание и список проектов, бейджи и выход. Добавлена доступная с клавиатуры подсказка о рабочих пространствах на RU/EN.
- Общий `TaskNavigator` перенесён из содержимого задачи на уровень оболочки обеих ролей. На desktop он начинается у верхней границы, содержит логотип с правильным адресом и занимает всю высоту viewport. Sticky-шапка и содержимое занимают колонку справа и расширяются при скрытии навигации. На mobile тот же список переносится через существующий Teleport в drawer; логотип не добавляет строку. Состояния аккордеонов, настройки скрытия, загрузка данных и управление панелями сохранены.
- Один `Breadcrumbs.vue` используется административной оболочкой для проекта, его разделов, создания проекта и создания/редактирования/просмотра идеи. Ссылки используют Vue Router и существующие данные; последний элемент без ссылки, с `aria-current="page"`. UUID не показываются, длинные подписи сокращаются. На списке проектов, авторизации и клиентских страницах крошек нет. Повторяющие их ссылки возврата над административными формами удалены.
- Для коротких drawer-панелей исправлен обход фокуса Tab/Shift+Tab на границах списка, сохранив Escape, модальность, закрытие по фону и возврат фокуса. Существующие предупреждения о несохранённых изменениях и явное сохранение работают также при переходе через крошки и выходе из профиля.
