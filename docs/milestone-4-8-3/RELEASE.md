# Project Brief 0.4.8.3

Клиентские Email/Push/Telegram preferences сохраняются автоматически. Общая с администратором очередь записи исключает параллельные PATCH, дубликаты и потерю быстрых изменений разных каналов; интерфейс принимает подтверждённый ответ и показывает ошибку при отказе. Telegram preference сохраняется отдельно от подключения аккаунта.

Обсуждения владельца, разработчика и клиента разделены на доступные с клавиатуры вкладки «Общие комментарии» и «Последние комментарии». Счётчики независимы и вычисляются сервером по всем страницам. Mark-all ограничен активной вкладкой; старый API без kind сохраняет прежнюю семантику. Draft, отдельная пагинация и сортировка сохранены. Глубокие ссылки загружают нужный комментарий за пределами первой страницы, не отмечая его прочитанным.

Patch для 4.8.2 be2b883: два PHP-файла и frontend assets. Нет миграций, новых зависимостей, изменений vendor или .env. Инструкция обновления и отката — PRODUCTION.md. Push, deployment и GitHub Release не выполнялись.
