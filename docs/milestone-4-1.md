# Milestone 4.1 — AI Task Assistant: отчёт

Реализована интеграция с Groq через Laravel HTTP Client и Structured Outputs.
Предложение доступно в форме создания и редактирования, редактируется перед
применением и меняет только локальные поля. Вопросы и предложения разделения
отображаются отдельно. Сохранение задачи выполняет существующая кнопка формы.

## Проверки

- `npm test` — **129/129**, без пропусков.
- `cd api && php artisan test --compact` — **238/238**, 3174 assertions.
- В том числе AI Feature-тесты — **55/55**: успешный ответ для owner,
  назначенного admin и клиента; некорректные вход/выход; timeout/429/401/500;
  отключённый AI и отсутствие ключа; конкуренция за квоту, суточный сброс UTC;
  чужие workspace/проекты, неназначенные и неактивные участники, отозванные ссылки.
- `npm run build` — успешно.
- `npm run format:check` — успешно.
- `cd api && vendor/bin/pint --dirty --format agent` — успешно.
- `git diff --check` — успешно.
- В локальном браузере проверены: AI недоступен при пустом тексте; после ввода
  кнопка активна; demo объясняет недоступность генерации; Escape закрывает окно,
  возвращает фокус и сохраняет текст формы; ошибок и предупреждений консоли нет.

Тесты AI запрещают неожиданные исходящие HTTP-запросы. В провайдерном payload
проверяется точное совпадение пяти полей формы, без персональных данных из проекта,
приватных заметок, комментариев, других задач и языка интерфейса. Ошибки провайдера
не возвращают исходный текст или ключ. Запись задач/истории при генерации отсутствует.
Реальный вызов Groq с рабочим ключом не выполнялся; качество реальной генерации и
доступность конкретного аккаунта провайдера нужно проверить после настройки.

## Запуск

В `api/.env` задайте `AI_ENABLED=true`, `GROQ_API_KEY` и
`GROQ_MODEL=openai/gpt-oss-120b`; ключ остаётся исключительно на сервере.
По умолчанию лимиты — `AI_REQUESTS_PER_MINUTE=5` и
`AI_WORKSPACE_DAILY_LIMIT=50`, общие для workspace. Нужен постоянный общий cache;
очистка cache сбрасывает счётчики. Ошибочные попытки после обращения к провайдеру
расходуют квоту. Суточный лимит обновляется в 00:00 UTC.

Для локальной интеграции frontend: `VITE_DATA_SOURCE=api`, затем `npm run api:dev`
и `npm run dev`. Если Laravel config закэширован, выполните в `api`
`php artisan config:clear`. Подробности — в README, раздел Milestone 4.1.

Работа выполнена в `codex/ai-task-assistant` от локальной
`feature/saas-foundation`, без переписывания истории. Deployment, изменения
production-базы и отправка коммитов в GitHub не выполнялись. SHA локального
коммита предоставляется в итоговом сообщении чата.
