# ProjectBrief 0.6.2

- PDF полностью переведён в браузер: JSON API, pdfmake, Web Worker. Серверный PDF и Dompdf удалены; fallback отсутствует.
- DOCX по-прежнему создаётся PHPWord на сервере, с сохранением CJK-встройки.
- Экспорт использует две колонки на desktop, одну на планшете/mobile; общая область действий PDF/DOCX, этапы, отмена и повтор.
- Новые проекты в admin и REST создаются без разделов и задач. Первый раздел добавляется вручную с существующим правом manage_structure.
- RU/EN/TR/ZH-CN, клиентский allowlist, scope, расчёты и валюта проекта сохранены.
- Прототипные переключатели и отдельная точка входа удалены. Библиотека и шрифты остаются ленивыми; публичный TTF кеш не содержит проектных данных.
- Safari и реальные смартфоны не объявляются подтверждёнными. Исторические отчёты 6.0/6.1 сохранены в Git.

Обновление требует согласованной замены public/private/vendor, сохранения .env/storage и проверки новых hashed assets. См. PRODUCTION.md и DEPLOY-JINO.md. Новых миграций данных нет. Push/deployment не выполнялись.
