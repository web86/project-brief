# Project Brief 0.4.7.1 — Navigation & Layout Polish

База `3023f57` (4.6.1), ветка `codex/milestone-4-7-1-navigation-layout`.

- Проектный сайдбар вместо глобального в контексте проекта; единый ProjectNavigation
  используется в сайдбаре и существующем drawer страницы идеи.
- Логотип возвращён в верхнюю часть левого проектного сайдбара.
- «Все проекты» вверху, личные уведомления и выход сохранены. Корзина стоит
  последней с разделителем и открывает один общий существующий диалог.
- Горизонтальное проектное меню удалено из layout.
- Главная проекта: один H1, равные колонки 50/50 с прогрессом и добавлением идеи,
  адаптация для tablet/mobile и длинных названий.
- Native мобильный select статусов со счётчиками и общим состоянием фильтра.
  Скрытый раздел сбрасывается при переходе на mobile.
- Навигатор задач, черновики, защита несохранённых изменений, touch drag,
  корзина и клиентский интерфейс сохранены.
- При переключении workspace или получении отказа доступа старый проектный
  контекст очищается; отложенный ответ списка не возвращает удалённый пункт.

В доступной базе нет маршрутов команды проекта, личного профиля и безопасности.
Для них не добавлены фиктивные ссылки. Новых миграций, зависимостей и env нет.
Telegram/Deno и система отправки уведомлений не менялись.

Прочитайте PRODUCTION.md перед обновлением. ZIP содержит assets и production
vendor; uploads, .env и APP_KEY должны быть сохранены оператором.
