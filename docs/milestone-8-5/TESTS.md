# Milestone 8.5 — проверки

Все проверки используют одноразовые SQLite БД/QA-копии приложения и локальные HTTPS-сайты. Production DB, Jino/FPM и внешняя SMTP-доставка не проверялись и не изменялись.

- `npm test`: **383 / 383**, включая owner-only глобальную навигацию RU/EN/TR/ZH-CN, смену полномочий workspace, router guard и подготовку step-up на `/admin/administrators`.
- Focused Laravel: **29 tests / 326 assertions** для WorkspaceAdministratorsTest, AdministratorManagementMigrationTest и FlexibleAccountSecurityTest. Покрыты приглашение без проекта, normalized duplicate email, drafts, изменение pending invitation, несколько назначений, индивидуальные права, narrow removal, деактивация, tenant isolation, owner protection, свежий step-up и independent source keys.
- Upgrade test накатывает старую схему, создаёт реальные User/membership/project permissions/pending invitation, затем дважды применяет новую миграцию с rollback. Сравнивает прежние строки и hashes, подтверждает работоспособность старой ссылки. Пользователи и права не пересоздаются.
- `tests/administrators.browser.mjs`: **4 группы сценариев, 0 JS errors**, **64 снимка**: 4 экрана × RU/EN/TR/ZH-CN × 1440/390 px × light/dark. Есть реальная работа фильтра, draft/duplicate, independent permissions, массовое назначение и удаление только одного проекта, source creation/key/one-time secret, manual projects, mobile drawer, deactivation и owner→developer workspace switch. Нет горизонтального overflow. Evidence: `artifacts/milestone-8-5/sqlite/results.json`.
- `tests/client-sso.browser.mjs`: **12 сценариев, 9 снимков**, существующая production frontend regression через **два локальных HTTPS-сайта**: provenance, source/key/client revoke, handoff, single-use/TTL/Origin/binding, старые сессии и Magic Link fallback. Evidence: `artifacts/milestone-8-5/sso/sqlite/results.json`.
- `tests/account-security.browser.mjs`: **23 сценария**. Реальные UV-подписи виртуального WebAuthn authenticator в Chromium, TOTP/recovery, cancel/retry/fallback, сохранение одного PATCH после свежего подтверждения, клиентская сессия и Firefox serializer/user activation с mock provider. Evidence: `artifacts/milestone-8-5/security/browser-results.json`. Physical Touch ID и WebKit не выполнялись.
- Снимки desktop/mobile и light/dark проверены визуально; исправлено обрезание ручного SSO-списка старым ограничением высоты. Исходные артефакты прежних milestones сохранены.

Полный Laravel suite, каноническая production ZIP-сборка и extracted runtime фиксируются в RELEASE-ARTIFACT.json после финального прохода. Для полного suite локальному PHP нужен memory_limit=512M: `php -d memory_limit=512M vendor/bin/phpunit` либо отдельный QA ini через PHP_INI_SCAN_DIR, который наследуется процессом `artisan test`. Это тестовая настройка, production PHP config не меняется.

Канонический builder `./bin/build-release` требует чистый commit, запускает frontend/Laravel/build, устанавливает production vendor в staging, исключает tests/factories/QA/runtime data/secrets, сверяет внутренние SHA-256, CRC и freshly extracted runtime. Последний также проверяет свежий WebAuthn step-up и сохранение прав через новый глобальный маршрут из скомпилированных assets. ZIP не содержит source tests или QA screenshots.

Предыдущие локальные ошибки тестов были вызваны ожиданием прежних project routes, selection скрытого drawer, отсутствием owner в списке администраторов и тестовым языком после visual matrix; исправлены ожидания текущего контракта. Первоначальный full suite завершился на системном PHP memory_limit=128M в существующем image-optimization test; повтор выполняется с QA ini 512M. Никакие security defaults или production limits для прохождения тестов не ослаблены.
