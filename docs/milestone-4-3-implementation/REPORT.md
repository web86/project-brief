# Milestone 4.3 — UI/UX и коммуникации

Ветка: `codex/milestone-4-3-ux-communications`.

## Изменения

1. Внизу карточек задач администратор видит заполненные часы и иконку стоимости. Сумма в валюте проекта появляется при наведении или фокусе, в том числе с мобильной клавиатуры. Нулевые значения сохранены. Клиентский API по-прежнему не возвращает финансовые поля и технические заметки.
2. Внутренний переход сохраняет текущую страницу, блокирует её через `inert` и полупрозрачный слой со спиннером. Данные и ленивые компоненты подготавливаются до переключения. Временные ошибки оставляют прежние URL и данные; предусмотрены отмена, повторные переходы, ошибки чанков и подтверждение выхода с черновиком. Настройки уведомлений также подготавливаются до перехода. Начальный запуск использует существующий стартовый экран.
3. Успешные и информационные toast имеют тёмно-зелёный фон и светлый текст; ошибки — красный. Существующие длительность, пауза при наведении/фокусе, действия и закрытие сохранены.
4. Язык интерфейса администратора теперь сохраняется в аккаунте. Для всех семи существующих типов писем и тестового письма язык определяется отдельно по получателю непосредственно при доставке. RU/EN включают тему, содержимое, кнопку и подписи. Отсутствующее предпочтение использует прежний default: конфигурацию администратора или EN клиента. Существующая доставка после commit/при завершении запроса сохранена.
5. «Обсуждения» добавлены сразу после «Идеи». Общие сообщения используют существующую таблицу `comments` с пустым `task_id` и привязкой к проекту. Лента комментариев задач отсортирована по дате и ID, загружается по 25 записей через cursor, содержит автора, задачу, раздел, фрагмент и ссылку на комментарий. Есть фильтр непрочитанных, бейдж, точечное прочтение и явная команда «Отметить всё прочитанным». Открытие вкладки ничего не отмечает. В задаче отмечаются только видимые комментарии; целевой комментарий прокручивается в область просмотра и выделяется на 2,5 секунды. Собственные сообщения исключены. Черновик общего сообщения сохраняется в памяти между вкладками и очищается при смене личности/рабочего пространства.
6. Экспорт получил выключенный по умолчанию флажок «Показать технические заметки». Общий построитель данных PDF/DOCX добавляет непустые заметки под задачей с локализованной подписью. Фильтры, порядок, компактная строка метаданных и права экспорта сохранены.

## Миграция и совместимость

Добавлена миграция `2026_10_20_092216_add_discussions_and_user_locale.php`: `users.preferred_locale`, nullable `comments.task_id`, `comments.project_id`, индекс хронологии и точные пары пользователь/комментарий в `comment_reads`.

Старые строки комментариев не перемещаются и не копируются. Из существующих `project_reads` переносятся подтверждённые прочтения клиентских комментариев, сопоставленные через `task_history.meta.commentId`; сообщения без достоверного соответствия не скрываются автоматически. Старый счётчик активности проекта сохранён независимо от счётчика комментариев. Очистка/отзыв доступа и проверки workspace/project остаются существующими.

Перед использованием новой версии нужно выполнить обычную миграцию БД (`cd api && php artisan migrate`). Рабочая и production БД в рамках этой задачи не мигрировались. Push, deployment и GitHub Release не выполнялись. Изначальные незакоммиченные материалы публичного preview не изменялись.

## Ограничения

- В исходной реализации не было общего блока комментариев проекта или его хранения. Поэтому добавлен новый блок в существующую модель комментариев; доступ к нему предоставлен администраторам проекта. Права клиентов на прежние комментарии задач сохранены.
- Браузерные проверки выполнены в Chromium с подменённым API; backend проверен отдельно feature-тестами на SQLite. Физические устройства, production MySQL, реальный SMTP и внешние push-сервисы не использовались. Письма перехвачены `Mail::fake`, внешняя отправка отсутствовала.
- Исходное приложение поддерживает PDF и DOCX; отдельного legacy DOC-экспортера нет, он не добавлялся.
- Новый черновик общего сообщения хранится до перезагрузки страницы/смены личности. Существующие механизмы черновиков задач и защиты от потери изменений сохранены.
- Счётчики обновляются при существующих загрузках/переходах и действиях чтения. WebSocket и отдельная система чатов не добавлялись.
