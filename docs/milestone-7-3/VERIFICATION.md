## Apache rule reasoning and gates

Paths are anchored to known root namespaces; query strings are not deny inputs. The exact root index.php alone is exempt from executable checks, including internal rewrites. Existing hostile files are tested, not merely nonexistent paths. Missing-assets rules precede SPA fallback. No blanket reject of unknown SPA routes/methods, UUIDs, User-Agent or country. Public font-license TXT, SVG/JSON/manifest and protected ZIP downloads stay legitimate.

ErrorDocument overrides are gated by the server Define `PROJECT_BRIEF_NATIVE_ERRORS`, **inactive by default** because Jino permission and inheritance are UNKNOWN. The enabled variant is tested against inherited dynamic PHP error pages; the default variant is tested with native host defaults. Without preflight, no claim is made that Jino's inherited handlers avoid PHP. Other guards reuse existing rewrite capability; actual AllowOverrideList and static header support still require confirmation before installation.
